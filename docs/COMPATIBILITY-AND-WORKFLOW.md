## 结论

原版只有 DSH 版本范围声明，不能称为运行时自动适配。现已补入运行时版本、服务和模型能力识别，以及安全降级分支。自动适配限于已知 API 家族和确实可识别的接口差异；不会承诺兼容所有将来版本，也不自动改动用户的 DSH profile 或模型账号。

本插件覆盖“输入 → 需求 → 现成项目选择与准备 → 基础模型样例 → 调整 → 原生用户批准 → 模型/动画/渲染 → 交付”的代码路径。它仍需要可用的本地算力和具体后端。尚未进行真实端到端执行，不能把源码中的路径覆盖当作用户电脑上已经成功运行。

## 对用户期望的逐项判断

1. 一句话先做基础模型，再问特殊需求与精细化：有 quick 编排路径，预览必须保存实际工程；依赖准备完成后由当前 DeepSeek 连续调工具执行。
2. 有明确要求时深入追问：有逐轮 1—3 问、已知事实、主动更正和摘要确认，不重复要求用户查显卡。
3. 已有更合适的本地项目优先：识别已知源码与 local-3d.adapter.json；支持 preferredProjects。不能保证自动推断任意项目的私有 API。
4. 没有项目时克隆并调用：有已登记官方项目的隔离准备入口；权重、许可和磁盘影响通过具体问题说明。系统级工具和驱动不静默安装。
5. 不增加 Key 或付费生成服务：默认当前 DeepSeek 与本地项目；ComfyUI 限回环地址，拒绝已知云生成节点和认证字段。自定义项目的 localOnly 声明不等于全面审计其代码。
6. 图片与视频复刻：本地图生模型与静态 COLMAP 有调用路径。动态视频不能保证精确恢复遮挡背面和动作；采用可编辑场景与动作近似复刻，明示推测。
7. 高精度模型与精致动画：有现成结构、材质、骨骼、镜头、动画和渲染工具的编排入口；实际质量取决于资产、算法、显存、方案和用户反馈。高面数不代表精度达标。
8. 自动装配全部社区工作流：目前不具备对任意 ComfyUI 节点与权重的一键自动装配能力。使用现成 API 工作流或适配声明；缺少时走 Blender 真三维预览，不用占位图冒充接通生成模型。
